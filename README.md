# Projet
Garazy est une application web développée avec Angular pour le frontend et MongoDB pour la gestion des données, s’inscrivant dans une architecture de type MEAN (MongoDB, Express, Angular, Node.js).

L’application permet de gérer efficacement les activités d’un garage automobile, notamment la gestion des véhicules, des clients, des réparations et des rendez-vous. Elle repose sur une API backend (Node.js/Express) qui assure la communication entre l’interface utilisateur et la base de données.

L’objectif principal est de proposer une solution simple et performante pour le suivi des opérations, l’organisation des interventions et l’optimisation de la gestion quotidienne d’un garage.
